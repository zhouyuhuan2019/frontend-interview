先看这段代码，猜猜每一行输出什么：

```js
console.log(0 || '默认值')
console.log('' ?? '默认值')
console.log(0 ?? '默认值')
console.log(null ?? '默认值')
console.log(1 && 2)
console.log(0 && '不会执行')
console.log(false || 'x')
```

## 参考答案

```text output
默认值

0
默认值
2
0
x
```

逐条拆开反直觉点：

- `0 || '默认值'` → `'默认值'`：`||` 把 `0` 当假值，直接短路取右操作数。
- `'' ?? '默认值'` → `''`（上面输出里的空行）：`??` 只在左操作数是 `null` / `undefined` 时才回退，空字符串被原样保留。
- `0 ?? '默认值'` → `0`：`0` 不是 `null` / `undefined`，保留左操作数。
- `1 && 2` → `2`：`&&` 找到第一个假值就返回它，否则返回最后一个操作数。
- `0 && '不会执行'` → `0`：左操作数是假值，短路返回它本身，右边根本不执行。

**核心结论：`&&` 和 `||` 返回的永远是「被选中的那个操作数本身」，并不是布尔值。** 想要真正的布尔值，必须用 `Boolean(x)` 或 `!!x` 显式转换。

对照一览：

| 运算符 | 取右边操作数的条件 | 返回值的本质 |
| --- | --- | --- |
| `a \|\| b` | `a` 是假值时 | `a` 或 `b` 的原值 |
| `a && b` | `a` 是真值时 | `a` 或 `b` 的原值 |
| `a ?? b` | `a` 是 `null` / `undefined` 时 | `a` 或 `b` 的原值 |

## 原理讲解

`||` / `&&` / `??` 都是**短路求值**，返回值是被选中的操作数，不做布尔化：

- `a || b`：`a` 为假值（`0`、`''`、`false`、`null`、`undefined`、`NaN`）时取 `b`，否则取 `a`。
- `a && b`：`a` 为假值时取 `a`，否则取 `b`。
- `a ?? b`：仅当 `a` 是 `null` 或 `undefined` 时取 `b`，否则取 `a`。它只认「空值」，不认 `0` / `''` / `false`。

```js run
// || 会吞掉 0 和 ''，给「有意义的 0」兜底时就是 bug 源头
function setVolume(vol) {
  return vol || 100 // 用户传 0（静音）会被当成没传，覆盖成 100
}
console.log('|| 兜底:', setVolume(0)) // 100，静音被吃掉

function setVolumeFixed(vol) {
  return vol ?? 100 // 只有 null/undefined 才兜底
}
console.log('?? 兜底:', setVolumeFixed(0)) // 0，正确保留

// 返回的是操作数本身，不是布尔值
console.log('1 && 2 =', 1 && 2) // 2
console.log('0 || "x" =', 0 || 'x') // x
console.log('typeof (1 && 2) =', typeof (1 && 2)) // number
```

```text output
|| 兜底: 100
?? 兜底: 0
1 && 2 = 2
0 || "x" = x
typeof (1 && 2) = number
```

**实际开发中的正确写法**：

1. 给数值 / 字符串参数兜底时用 `??`，别用 `||`——`0`、`''`、`false` 常常是合法值（音量、数量、开关）。
2. 需要布尔结果时显式转换：`const enabled = !!rawValue`。
3. `??` 不能和 `||` / `&&` 不加括号混用，要写就加括号：`(a ?? b) || c`。

## 追问与易错点

- **`??` 和 `||` 能混用吗？** 不能直接混用，`a ?? b || c` 会抛 `SyntaxError`，必须加括号写成 `(a ?? b) || c`。
- **`a ?? b ?? c` 可以吗？** 可以，`??` 与 `??` 之间不加括号是合法的，从左到右短路。
- **`'' || '默认值'` 和 `'' ?? '默认值'` 一样吗？** 不一样。前者得 `'默认值'`，后者得 `''`。表单里空字符串常是有效输入，用 `||` 会被误覆盖。
- **`NaN || 1` 和 `NaN ?? 1` 呢？** 前者得 `1`（`NaN` 是假值），后者得 `NaN`（`NaN` 不是 `null` / `undefined`）。
- **`a || b` 的结果一定是布尔吗？** 不是，它是「逻辑或」但返回操作数原值，别当返回布尔的运算符用。
